# Shop Ledger

Offline-first PWA for a clothes shop: stock lots, sales, dues, expenses and profit.

```bash
npm install
cp .env.example .env.local   # fill Supabase URL and key
npm run dev
```

Database: run `supabase/migrations/0001_init.sql` in the Supabase SQL editor.
Project rules for Claude Code: `CLAUDE.md`. Specs: `.claude/docs/`.
